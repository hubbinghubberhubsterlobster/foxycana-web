# Foxycana – Web-Version 🦊

Die Lorcana-Sammler-App im Browser (z. B. fürs iPhone): **https://hubbinghubberhubsterlobster.github.io/foxycana-web/**

In Safari öffnen → Teilen → „Zum Home-Bildschirm“. Jede Person hat ihre eigene Sammlung, sie liegt nur im
Browser auf dem eigenen Gerät. Karten, Cardmarket-Preise, Kurse und Meta werden täglich automatisch aktualisiert.

Inoffizielle Fan-App, nicht verbunden mit Disney oder Ravensburger. Daten: LorcanaJSON, Cardmarket-Preisguide, EZB, inkdecks.com.
